# 사전 학습 데이터

[English](README.md) | 한국어

`v1.txt`는 뇌 코덱의 타고난 지식이에요([SPEC.ko.md](../SPEC.ko.md) §6.4.11, 부록 B). 작은 블록을 압축하기 전에 코덱이 이 글을 먼저 읽고 배워 두기 때문에, 흔한 단어와 코드, 데이터 형식을 이미 아는 상태에서 시작해요. 그래서 작은 파일이 9%쯤 더 작아져요.

이 파일은 포맷의 일부예요. 한 바이트만 바꿔도 호환이 깨지므로 나중에 새 버전이 필요하면 새 파일로 추가해요. 이 목적으로 따로 쓴 글이고, 저장소의 다른 파일과 같은 MIT 라이선스로 공개해요.
